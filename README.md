# File Type Identification Tool (Magic Number Analysis)

## 🚀 Overview
This is a Python-based file analysis tool that identifies the true file type of files using magic numbers instead of relying on file extensions.

It can detect mismatched or potentially suspicious files, reflecting real-world techniques used in cybersecurity and digital forensics.

---

## 🛠️ Features
- Scan files and folders
- Extract and analyse magic numbers
- Identify real file types
- Detect mismatched file extensions
- Simple GUI interface

---

## 🧠 Technologies
- Python
- JSON (signature database)
- Tkinter (GUI)
